# CSES Set 1

This workspace is set up for solving CSES problem set 1 in C++ with sample input/output files and VS Code debugging support.

## Folder structure

- Each problem is in its own folder.
- Every folder contains:
  - `main.cpp` for the solution
  - `input.txt` for sample input
  - `output.txt` for the expected output

## Run / debug

1. Open a problem folder.
2. Press `Ctrl+Shift+B` to build the active C++ file.
3. Press `F5` to start debugging the active file.
4. To compare with sample output, check the corresponding `output.txt` file.

## Notes

- The workspace is configured for `g++` on Windows.
- Use the C/C++ extension in VS Code for the best experience.
